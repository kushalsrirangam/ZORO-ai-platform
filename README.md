# ZORO AI Platform

**Start Date:** June 3, 2026, 3:21 PM  
**Owner:** Kushal Sri Rangam  

## Vision

ZORO AI Platform is an end-to-end real-world AI/software engineering project designed to build strong job-ready experience across planning, system design, frontend, backend, databases, AI/ML, cloud deployment, DevOps, monitoring, security, and documentation.

The goal is not just to build an app, but to understand how a real company takes a project from idea to production.

## Planned Tech Stack

This will evolve as the project grows.

- Frontend: React, TypeScript, Tailwind CSS
- Backend: Python, FastAPI
- Database: PostgreSQL
- AI/ML: scikit-learn, sentence-transformers, LangChain or LlamaIndex
- Vector Database: FAISS or Chroma
- DevOps: Docker, GitHub Actions
- Cloud: AWS or Render/Railway/Vercel depending on phase
- Monitoring: Logging, metrics, error tracking

## Project Philosophy

Every phase should answer:

1. What are we building?
2. Why are we building it this way?
3. How would a real company do this?
4. What skill does this teach me?
5. How can I explain it in an interview?
